CDC Heartbeat Mechanism (heartbeat.interval.ms = 5000)

During low-activity windows, PostgreSQL replication slots can lag in advancing their Log Sequence Numbers (LSN), causing WAL files to accumulate indefinitely until the server runs out of disk. LakeFlow injects automated heartbeat signals every 5 seconds to guarantee continuous LSN advancement and prevent WAL disk exhaustion.

2

Deterministic Deduplication with Watermarking

Spark Structured Streaming deduplicates records based on the composite key (record_key, source_lsn) within a 10-minute event-time watermark. This guarantees strictly exactly-once delivery semantics even during Kafka rebalances or network flakiness.

3

Off-Heap RocksDB State Store Provider

Traditional in-memory Spark state stores cause catastrophic JVM garbage collection pauses under high cardinality. LakeFlow switches to org.apache.spark.sql.execution.streaming.state.RocksDBStateStoreProvider with disk backing, eliminating heap bloat and GC pauses completely.

4

Iceberg Small File Prevention (128MB + Zstandard)

Streaming writes can easily cause the dreaded "small files problem" (millions of 50KB Parquet files). LakeFlow enforces write.target-file-size-bytes = 134217728 (128MB) with Zstandard level 3 compression, maintaining healthy manifest sizes and eliminating compaction debt.
